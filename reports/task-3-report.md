## Frontend Changes

- `api-client.ts` now reads the persisted token from `localStorage`, attaches `Authorization: Bearer <token>`, clears auth on 401/403, and redirects to `/login`.
- `AuthContext` now calls real `POST /auth/login` and `POST /auth/register`, stores `{ token, user }` in `localStorage`, exposes `error`, and removed all `sessionStorage` mock auth.
- Added `frontend/src/services/auth.ts` for typed auth calls using the BFF `{ token, user }` response.
- Added `QueryClientProvider` at the app root.
- Dashboard now uses TanStack Query for `/goals`, `/gamification/summary`, `/gamification/milestones`, and `/companion`; deposit submission calls `/deposits/log` and invalidates BFF-backed queries.
- `GoalCreatePage` and `OnboardingPage` now call `/goals/create`; onboarding Firefly PAT step calls `/firefly/set-pat`.
- `DepositButton` now calls `/deposits/log`.
- Wardrobe and ShareCard kept hardcoded cosmetics/share URL per spec and now include `// TODO(v2): backed by /avatar + /share endpoints.`
- Added `frontend/.env.local` with `VITE_BFF_URL=http://localhost:8787`.
